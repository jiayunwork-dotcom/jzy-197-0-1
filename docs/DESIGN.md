# 数据校正设计说明

## 1. 问题表述

回路用有向图描述：节点是给矿点、粗选/精选/扫选作业、合流点等；物流
`s: u → v` 连接两个节点，端点取保留 id `@env` 表示与系统环境（边界）相连。
每股物流有一个干矿量状态 `F_j`，对每种考查元素 `e` 有一个品位状态
`g_ej`（单位：百分点，0~100）。

测量分两类：

| 类型 | 测量量 | 权重 |
|---|---|---|
| `flow` | 干矿量 `F_j`（t/h） | 相对标准差 RSD |
| `grade` | 品位 `g_ej`（%） | 相对标准差 RSD |

每个内部节点 `n` 必须满足守恒式（`A` 为关联矩阵，入为 +1、出为 −1）：

```
质量：  Σ_j A_nj F_j = 0
金属：  Σ_j A_nj F_j g_ej = 0     对每种元素 e
```

校正模型为带等式约束的加权最小二乘：

```
min   Σ_{i ∈ 已测} ((x_i − y_i) / σ_i)²
s.t.  上述全部守恒式 = 0
```

未测变量作为权重为 0 的状态变量进入同一方程组——不给它们人为塞大方差，
因此“能否由守恒关系唯一确定”完全由约束的结构决定（见第 4 节）。

## 2. 测量误差模型与默认 RSD

相对标准差（1σ 相对误差）的默认值取自选矿流程考查常见手段的经验量级：

| 类别 | 默认 RSD | 依据 |
|---|---:|---|
| `flow`（皮带秤 / 矿浆流量计+浓度反算干矿量） | **2.0%** | 电子皮带秤约 1%~3%；流量+浓度联合反算误差更大 |
| `grade`（X 荧光 / 化学分析） | **5.0%** | 常规分析相对误差 3%~8%，低品位样品更高 |

默认值可在三处覆盖：

1. 单个测量：`{"stream_id", "type", "value", "rsd": 0.03}`；
2. 一次校正按类别覆盖：`settings.default_rsd = {"flow": 0.01, "grade": 0.08}`；
3. 改源码 `reconciliation/measurements.py:DEFAULT_RSD`（改后需在变更说明中记录）。

绝对标准差：

```
σ_F   = max(rsd·|F_meas|, 1e-6 · 最大已测流量)
σ_g   = max(rsd·|g_meas|, 1e-4 百分点)
```

绝对下限保证测量值接近 0 时权重不发散，同时流量下限按回路量级自适应，
使“流量同比缩放”的不变性严格成立。

## 3. 求解方法：逐次线性化（Gauss-Newton）+ KKT

金属平衡 `F·g` 是双线性项，约束整体非线性。在当前工作点 `x^(k)` 一阶展开：

```
f(x) ≈ f(x^k) + J(x^k) Δx = 0
```

解带线性等式约束的二次规划。内部用归一化坐标（流量除以回路特征流量、
品位除以 100），KKT 方程组为

```
[ D W² D    (J D)ᵀ ] [Δz]   [ −D W² D(z − z_y) ]
[ J D        0      ] [ λ ] = [ −f                ]
```

`W = diag(1/σ)`（未测位为 0），`D` 为尺度对角阵。用 SVD 最小二乘求解，
因此合流节点等导致的线性相关约束行不会造成数值失败。

**为什么选逐次线性化而不是按节点分解：**

* 不依赖网络的特殊结构——循环中矿、合流点、多元素统一处理；
* 每步一次线性代数，在几十股物流×几种元素的规模上亚毫秒~毫秒级；
* 在解附近二阶收敛，手算例 1 步、复杂回路十余步即到机器精度；
* 未测变量、可观测性、粗差检验共享同一个 Jacobian，理论闭环。

迭代中对会使流量变负的步长做简单回溯阻尼（保持物理可行）。

### 收敛判据与次数上限

* **残差判据**：所有节点质量/金属平衡残差的相对值
  `|残差| / max(节点经手量, …) ≤ tol_residual`，默认 **1e-10**
  （对外承诺 1e-9，留一个数量级余量）；
* 状态相对变化 ≤ `tol_step`（默认 1e-12）作为辅助；
* **迭代上限** `max_iter` 默认 **50**。达到上限未收敛时，结果照常返回，
  字段 `converged=false`、`iterations`、`residual_history`、
  `max_relative_residual` 如实给出，HTTP 仍是 200（这是计算结论，不是错误），
  绝不伪装成功；
* 输入本来完全平衡时初始残差即为机器零，**0 次迭代、校正量为 0**。

## 4. 可观测性分析

在工作点把 Jacobian 按列拆为已测列 `J_M`、未测列 `J_U`。未测变量
能被守恒关系唯一确定，当且仅当 `J_U` 列满秩；其零空间中的每个非零向量
代表一个“沿它扰动不改变任何守恒式”的不可识别方向。

一次 SVD 取零空间基后逐行判定：变量 `i` 不可观测 ⇔ 零空间基中存在
在 `i` 分量非零的向量。结果同时给出：

* `unobservable`：具体到哪一股的流量 / 哪个品位；
* `ambiguity_groups`：哪些变量属于同一个自由度（例如“精矿、尾矿流量
  之和固定、分配不可定”）。

对双线性约束，列秩在物理可行开集（正流量）内恒定，在迭代初值处评估即可。
存在不可观测变量时接口返回 **422 `unobservable`** 并列出变量；用户
显式 `accept_unobservable=true` 才接受最小范数形式的非唯一参考解，
结果里 `observability.observable=false` 明确标注。

冗余度（统计检验自由度）：

```
dof = rank(J) − rank(J_U)
```

即约束流形中真正施加在测量值上的独立限制数。

## 5. 粗差识别

* **整体 χ² 检验**：目标函数在“仅含给定随机误差”的零假设下服从
  χ²(dof)。`dof=0` 时明确提示“无冗余、不可检验”，不编造结论。
  χ² 生存函数用正则化不完全伽马函数（级数/连分式）自实现，无统计库依赖。
* **测量检验（measurement test）**：测量残差 `a = y − x̂` 的协方差

  ```
  Cov(a) = Σ_M − Σ_M J_Mᵀ (J Σ Jᵀ)⁺ J_M Σ_M
  ```

  逐测量给标准化残差 `z`（零假设下标准正态），|z| 超过阈值（默认 2.58，
  双侧 99%）标为嫌疑，按 |z| 排序给出首要嫌疑。用户可把该测量 id 放进
  `settings.excluded_measurement_ids` 重算；χ² 应显著下降。
* 剔除测量后它从已测集合移入未测集合，可观测性会重新评估——
  剔除关键测量可能导致不可观测，此时按第 4 节规则处理。

## 6. 金属平衡表与回收率

* 节点表：干矿/金属入量、出量、绝对与相对残差；
* 元素汇总：边界给矿金属合计 vs 边界产品金属合计、相对闭合差；
* 作业回收率：每股边界产品（`→ @env`）的校正金属量 / 全部边界给矿
  金属量 × 100%。手算例：精矿 `7.6923×20 / (100×2.0) = 76.923%`。
  多产品口径的走势接口也支持“全部产品合计回收率”。

## 7. 版本、幂等与并发

* **拓扑只追加**：每次录入产生新拓扑版本行（版本号递增），考查创建时
  必须声明使用哪一版；拓扑更新后旧考查仍引用旧版本，旧结果不受影响。
* **数据只追加**：补送/更正插入新数据版本，带 `parent_id`。
* **乐观并发**：提交修订时对考查行 `SELECT … FOR UPDATE` 并核对
  `parent_id == 当前版本`；不一致返回 **409 `version_conflict`**
  （携带服务端当前版本 id），后提交方合并后可重试，绝不静默覆盖。
* **结果幂等**：校正结果以
  `(campaign_version_id, sha256(规范设定 JSON))` 唯一存储；
  同版本同设定重复提交返回 `reused=true` 的已有结果（HTTP 200）。
  结果另存 `input_hash` 与拓扑版本 id，保证可复现、可审计。

## 8. 不变性质（均有测试覆盖）

1. 收敛后每个节点干矿/金属平衡残差相对值 `< 1e-9`；
2. 输入完全平衡 ⇒ 校正量为 0、目标函数 ≈ 0；
3. 所有流量同乘 `k>0` ⇒ 校正流量同比缩放、品位不变、回收率不变；
4. 某测量 σ 设很大 ⇒ 调整主要由它承担（加权调整小、原始调整大）；
5. 物流/节点换编号、打乱输入顺序 ⇒ 同构问题结果相同；
6. 未测流量不可唯一确定时点名拒绝，不给“看起来合理”的数。

## 9. 模块划分

```
reconciliation/
  topology.py      回路拓扑模型与校验（孤立点、悬空端点、元素声明）
  measurements.py  测量模型、RSD 默认值与绝对 σ、数据校验、稳定测量 id
  solver.py        逐次线性化 KKT 求解、初值、阻尼、收敛/上限
  observability.py Jacobian 秩与零空间结构可观测性、冗余度
  grosserror.py    χ² 整体检验与测量检验（含不完全伽马函数）
  balance.py       金属平衡表与回收率
  service.py       用例编排、设定指纹、版本对比、回收率走势
  repository.py    仓库抽象 + 内存实现（测试/无 DB 环境）
storage/
  postgres.py      PostgreSQL 16 仓库（psycopg3，行锁+唯一索引）
  schema.sql       表结构
api/
  app.py           Flask 路由与错误码映射
```
