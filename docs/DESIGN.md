# 设计说明

## 1. 模块边界与依赖

```
api.py ─┬─ topology.py ─────────── 校验、关联矩阵
        ├─ measurement_model.py ── 测量/变量布局、默认 rsd、权重
        ├─ reconciliation.py ───── 守恒约束、KKT 逐次线性化
        │     └─ observability.py   SVD 列秩可观测性
        ├─ gross_error.py ──────── χ² / 节点 / 测量检验
        │     └─ statsutil.py       正态、卡方 CDF/分位数
        ├─ reporting.py ────────── 结果/平衡表/回收率装配
        └─ storage.py ──────────── MemoryStore | PostgresStore（同一接口）
                                   └─ sql/schema.sql / jsonutil.py
```

纯算法模块不接触 Flask 与数据库，可单测；`storage` 不 import 算法；
`api` 是唯一的装配层。

## 2. 为什么选逐次线性化，而不是按节点分解

- 约束对变量是双线性的，雅可比解析且每步构造 O(nodes×streams)；
- 浮选回路有循环流/合流点，一个测量关联多个节点。按节点分解（如
  Q-R 分解逐节点消去）虽然能得到线性解，但循环流要反复协调，非线性时
  还要嵌套迭代；全回路一个 KKT 系统一次解出，残差可控、实现直接；
- KKT 系统里未测变量的权重位为 0，天然容纳“未测流量”，不需要给
  未测量人为填大方差（那会污染统计检验）；
- 每次解完同时拿到数值秩，可观测性/冗余分析复用同一次 SVD。

## 3. KKT 系统与尺度

变量向量 `x = [F_1..F_nf, G_{1,1..nf}, ..., G_ne,nf]`。
用对角矩阵 D（测量位取 σ，未测位取同元素/流量的典型量级）做坐标变换
`x = x_k + D·z`：

```
[ D W D   (H D)ᵀ ] [Δz]   [ -D W D · (x−x_m)/D ]
[  H D       0    ] [ λ ] = [ -h(x)               ]
```

缩放只改善条件数，不改变解（已由 `test_scaling_invariance` 和
编号无关用例覆盖）。求解用 `np.linalg.lstsq`：可观测时 KKT 非奇异，
lstsq 给唯一解；接受不可观测时 KKT 奇异，lstsq 给最小范数解，
秩由 SVD 返回用于诊断。

### 步长

KKT 牛顿步对双线性约束二阶收敛（标准手算样例 2 步到机器精度，
带冗余测量 3 步）。最初实现过 L2 罚函数 Armijo 线搜索，但加权坐标下
目标与残差量纲差异使罚因子把步长压到 ~1e-7 而停滞；现改为：
只做可行性回退（流量≥0、品位∈[0,1]）并要求相对残差平方和不显著
恶化（允许 1e-9 抖动）。背驰函数的教训记在代码注释里。

## 4. 可观测性的两个坑

1. **退化初值**：把所有未测流量、未测品位取同一个均值时，初始雅可比的
   列在给矿节点上共线（两股未测出料列完全相同），会把可观测误判成
   不可观测。初值改为确定性地轻微分散（0.8–1.2 倍均值），得到通用点。
2. **只判结构不够**：本问题结构矩阵（关联矩阵 A）恒定，但金属行
   随工作点变化。初值点和收敛点各判一次，不一致以收敛点为准并注明。

## 5. 粗差统计量口径

残差协方差 `Σ_h = H diag(σ²) Hᵀ` 一般奇异（有冗余投影零空间），
必须做特征分解取正特征子空间：

- 全局 χ² 在约简空间 `h̃ᵀ Σ_h⁺ h̃`，自由度 r = 正特征值个数
  = 测量数 − 未测变量数；
- 节点检验用物理坐标残差除以 `√diag(Σ_h)`；
- 测量检验用**实际调整量**与调整量协方差的对角余量
  `Σ_M − Σ_M Hᵀ Σ_h⁺ H Σ_M`。

r≤0 时三类检验都无意义，接口明确返回 `test_available=false`，
不硬凑 p 值。分位数用 Wilson–Hilferty 初值 + 对自写 χ² 生存函数的
二分法打磨（与查表值一致到 1e-10），不引第三方统计库。

## 6. 版本、幂等与并发

- 拓扑、数据各自整数版本自增，只追加不更新；
- 校正结果的“设定键”是规范化 JSON 的 sha256（剔除集合、迭代上限、
  容差、显著性、接受不可观测标志），与拓扑/数据版本组成复合键；
  PG 上是唯一约束，内存后端是线性查找，语义一致；
- 修订用乐观锁（`base_version`）。PG 实现 `SELECT … FOR UPDATE`
  后比对当前版本，冲突抛 409；内存后端用同一判定，因此并发用例无需
  数据库即可复现。

## 7. 已知边界与建议

- 金属量 = 流量×品位的纯双线性模型；若将来要把矿浆体积/浓度也纳入，
  需要在 `measurement_model` 增加变量并在 `build_residuals_and_jacobian`
  增加约束行，接口/版本机制不用动。
- 默认 rsd 是经验值（README 1.7），上线前务必用本厂平行化验与皮带秤
  校验数据替换；`rsd` 支持逐项传入。
- 规模假设：单回路几十股物流、单元素几百个以内变量，稠密 KKT
  （O(n³)，n 数百）足够；更大规模需要稀疏求解器（scipy 之外的选择
  需另行评估，本服务按要求不使用现成优化库）。
- 未做鉴权/多租户——厂内系统建议放在网关后或在 circuits 上加属主。
